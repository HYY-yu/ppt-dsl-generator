# PPT 备注 DSL 规范

编写或排查带 DSL 标记的 PPTX 模板时使用本参考。解析器会在读取备注前移除空白；请使用以下规范形式，确保模板意图清晰。

## 页面结构

```text
#页面类型
@封面页
#属性
@文本组件-主标题[4-18]
@图片组件-内容图-1
#逻辑关系
@总分
```

每张可复用页面必须且只能声明一个已识别页面类型：`封面页`、`目录页`、`章节过渡页`、`内容页`、`结尾页`。完整模板必须包含全部五种页面类型。

## 组件

```text
@文本组件-字段名[最小字符数-最大字符数]
@列表组件-列表语义-长度[最小项数-最大项数]
@列表组件-Item
@@文本组件-item字段名[最小字符数-最大字符数]
@图片组件-内容图-1
@图片组件-装饰图-2
@图片组件-品牌图-3
@序号组件-1
```

- `[n]` 表示固定长度 `n`；`[n-m]` 表示包含边界的范围。
- 文本长度按 Unicode 码点计数，不按字节或词数计数。
- 列表项组件必须紧随 `@列表组件-Item` 并使用 `@@`。
- 图片索引从 1 开始，按阅读顺序对应可见图片目标；页面仅有一个图片目标时可省略索引。

## 图片角色

- `内容图`：必须替换为用户素材或生成素材，除非用户明确批准保留该确切图片。
- `装饰图`：可保留，它属于模板视觉框架、背景或非语义装饰。
- `品牌图`：可保留，它属于标志或品牌识别元素。
- 未标注角色的模板图片将保守地视为 `内容图`。

## 编写规则

- 在预期作用域内，让每个文本占位符保持唯一。重复列表项占位符是预期行为；重复页面级占位符不是。
- 确保每个声明的文本字段都能在页面中找到可见的对应文本。
- 列表最小值和最大值应表达视觉容量，而不是希望填入的内容数量。
- 不要将来源事实或工作流说明编码到模板图片；应将它们标为 `内容图`。
- 新模板投入使用前，运行 `npm run lint-template -- --template "$TEMPLATE" --out "$OUT"`。
