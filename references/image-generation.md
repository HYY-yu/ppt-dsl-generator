# PPT 图片生成与填充

## 生成预算和选页

- 仅在文章图片不足，或封面、目录、章节过渡、结尾页确实需要装饰图时生成图片。
- 每个 Deck 生成 1-3 张，禁止超过 3 张。图片不足时优先保证一张图文内容页；剩余预算再考虑封面、章节过渡、结尾和目录。
- 每张生成图绑定明确的目标页和唯一资产引用，不跨页误用。

## 风格和构图

- 同一 Deck 只使用一个风格快照，当前仅使用既有风格：`hand_drawn_illustration`、`photo_illustration`、`monochrome_line_art`、`flat_vector`。
- 统一生成 1024×1024、1:1 正方形图片。
- 单一主体和所有关键视觉元素放在画布中央 60% 安全区，四周保留低细节留白，以适配宽、长、圆形和异形图片框的居中裁剪。
- 图片只承担气氛和主题装饰，页面文字仍是主要信息来源；图片不得承载决定性事实。

## 提示词硬约束

提示词必须明确要求：

- 完全无文字，不生成可读文字、伪文字、字母、单词、数字、标签、标题、标牌或类似书写的符号。
- 不生成 Logo、品牌、水印、UI、图表、表格、数据可视化。
- 不复述或渲染页面标题、核心信息和要点；这些内容只用于理解视觉主题。
- 明确图片是 `purely decorative supporting image`，并声明 `square 1:1`、`middle 60% safe area` 和统一风格描述。

## Runtime 填充合同

- 读取 PNG、JPEG、GIF 的真实像素宽高。
- 保持模板图片框的 `x/y/cx/cy` 和形状不变，使用居中裁剪填充，不拉伸图片、不改变图片框比例、不留空边。
- 源图比目标框更宽时对称裁剪左右；源图更高时对称裁剪上下；比例相同时不裁剪。
- 输出使用对称 `a:srcRect` 和 `<a:stretch><a:fillRect/></a:stretch>`，并清理模板遗留的 `a:tile` 或旧裁剪参数。
