# PPT 图片资产规划

当已确认大纲、且选定页面需要内容图片时，在模板匹配前执行本步骤。

1. 读取 manifest 的图片目标，只选择 `role` 为 `content` 的目标。
2. 建立精简资产计划：页码、`图片N`、要传达的信息、宽高比和素材来源优先级。
3. 优先复用用户提供的素材；没有合适素材时，使用 `imagegen` Skill 生成贴合主题的替换图片。
4. 确认每个生成或提供的本地路径都存在，再将路径交给模板匹配步骤。
5. 在 `DeckInput` 保留 `sourceRefs`，记录该页事实的来源；它们用于交付溯源，不是 PPT 演讲者备注。

模板匹配智能体输出纯 `DeckInput` JSON 时，不得编造路径，也不得在该步骤调用图片生成。
