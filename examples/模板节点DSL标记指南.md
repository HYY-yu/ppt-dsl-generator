# 如何制作节点 DSL PPTX 模板

本示例用于指导你把自己的 PowerPoint 设计稿制作成可编译模板。`ppt_example.pptx` 只是语法示例，不是默认模板；实际生成时必须提供你自己的 PPTX 路径。

## 1. 准备模板

1. 复制一份已经完成视觉设计的 PPTX，不要直接修改唯一原稿。
2. 保留母版、背景、装饰、字体、动画和页面尺寸。
3. 只给允许 Codex 替换的节点添加 DSL 名称；未标记节点会保持不变。
4. 在 PowerPoint 中打开“选择窗格”，直接修改节点或组合的名称。

## 2. 标记页面备注

每页备注只填写页面类型与逻辑关系：

```text
#页面类型
@内容页
#逻辑关系
@三点并列
@因果递进
```

页面类型只能是：`封面页`、`目录页`、`章节过渡页`、`内容页`、`结尾页`。一套可生成模板应覆盖这五种页面类型。

## 3. 标记普通节点

在选择窗格中使用以下名称：

```text
@文本[4-18]
@图片-1
@图片-2
@图标
@序号-01
@序号-001
```

- 文本必须声明长度范围 `[min-max]` 或固定长度 `[n]`，长度按 Unicode 字符计算。
- 同页多张图片使用 `@图片-1`、`@图片-2` 区分。
- `@序号-1`、`@序号-01`、`@序号-001` 分别生成 `1/2/3`、`01/02/03`、`001/002/003`。
- 页面级序号只放在章节过渡页，生成器会按章节顺序自动填写；列表项序号按 Item 位置自动填写，无需在内容输入中手工提供。
- 图标节点应预先设置好尺寸、位置和视觉样式，生成时会用本地 SVG 或 PNG 资源替换。

## 4. 标记固定列表

固定列表的 Item 数量不会变化，每个组件直接写列表 ID 和 Item ID：

```text
@1@1 文本[4-10]
@1@1 文本[20-80]
@1@1 序号-01

@1@2 文本
@1@2 文本
@1@2 序号
```

第一项声明完整组件合同和长度；后续项继承。每一项的组件种类和数量必须一致。同一项存在多个文本时，应让文本框尺寸和示例文字长度具有明显差异，便于编译器稳定匹配标题与正文。

## 5. 标记 Group 定长/变长列表

需要把背景、边框、图标、文本等作为完整 Item 管理时，将每个 Item 制作为 PowerPoint Group。定长列表的组合名称不声明范围：

```text
@1@1
@1@2
@1@3
```

这表示列表 1 固定为模板中的 3 项。需要允许数量变化时，只在第一组声明范围：

```text
@1@1[3-5]
@1@2
@1@3
```

这表示列表 1 允许 3–5 项，模板当前提供 3 个样例 Item。组合内部只标记组件，不再重复列表编号：

```text
@文本[4-10]
@文本[20-80]
@图标
@序号-01
```

后续组合内部可简写为 `@文本`、`@图标`、`@序号`。背景、边框、图标、文本和序号等所有需要一起复制的元素都应放进 Group。不要在同一个列表中混用 Group DSL 与固定列表 DSL。

Group 在页面中的外层位置会被当作布局样例保留。因此可以直接在模板中设计交错时间轴、上下阶梯或左右蛇形排列，无需增加额外 DSL。若希望每个动态 Item 保留动画并准确继承复杂布局，应在模板中预制到声明的最大 Item 数。

## 6. 自检清单

- 所有以 `@` 开头的名称都符合 DSL，不保留半成品标记。
- 页面备注只包含页面类型和逻辑关系。
- 第一项完整声明文本长度与序号格式。
- 后续列表项与第一项组件合同一致。
- Group 列表 Item 编号从 1 开始连续；定长列表不声明范围，变长列表的模板项数位于第一组声明的范围内。
- 目录项数量能够与最终章节过渡页一一对应。
- 每个章节过渡页模板都包含页面级 `@序号-*` 节点，其他页面不放页面级序号。
- 未标记节点确实不需要替换。
- 保存为 `.pptx`，不要另存为图片或 PDF。

## 7. 交给 Codex 编译

提供模板的实际路径，然后运行：

```bash
npm run compile-template -- --template "$TEMPLATE_PPTX" --out "$COMPILED_DIR"
```

`$TEMPLATE_PPTX` 必须指向本次用户提供的模板。编译产生错误时，根据页码、shapeId 和节点名回到选择窗格修正，再重新编译；不要通过删除校验或改用示例模板绕过错误。
