# PPT 备注 DSL 使用说明

本目录中的 [ppt_example.pptx](ppt_example.pptx) 是可学习的示例模板。打开后，在 PowerPoint 的“备注”窗格中查看每页的 DSL 标记；复制一页并调整版式时，也要同步更新该页备注。

## 这套规则解决什么问题

DSL 将“这一页是什么类型、哪些文字能替换、列表能放几项、哪些图片必须替换”写进演讲者备注。生成器据此解析模板，生成 manifest/schema，并在产出 PPTX 时校验内容容量和页面结构。

DSL 仅存在于模板的备注中。

## 每页的基本结构

每张可复用模板页在备注中按以下结构标记：

```text
#页面类型
@内容页
#属性
@文本组件-本页标题[4-12]
@图片组件-内容图-1
#逻辑关系
@总分
```

页面类型必须且只能有一个，可用值为：

- `封面页`
- `目录页`
- `章节过渡页`
- `内容页`
- `结尾页`

一个可用于完整演示稿的模板至少应覆盖这五种页面类型。

`#逻辑关系` 用于说明版式表达的关系，例如 `并列`、`递进`、`总分`、`对比`、`时间线`。它帮助生成阶段匹配合适的页面，不是展示给最终观众的文案。

## 文本组件

```text
@文本组件-字段名[最小字符数-最大字符数]
```

示例：

```text
@文本组件-主标题[4-18]
@文本组件-一句结论[12]
```

- `[n-m]` 是包含边界的长度范围。
- `[n]` 是固定长度，必须恰好为 `n`。
- 长度按 Unicode 码点计数，不按字节、中文词或英文单词计数。
- 每个页面级字段名必须对应页面中一个可见文本占位符，并且同一页不要重复页面级字段名。
- 文案必须严格满足该字段自己的 min/max；不要用统一的“标题应几字”规则覆盖 DSL。

## 列表组件

```text
@列表组件-列表语义-长度[最小项数-最大项数]
@列表组件-Item
@@文本组件-标题[2-8]
@@文本组件-描述[12-48]
```

`@列表组件-Item` 表示其后的 `@@` 行属于一个重复列表项。每个 item 可包含标题、描述、数字或图标等字段。

- 列表长度描述的是该页的视觉容量，不是期望填满的数量。
- 固定长度列表必须精确匹配；范围列表必须在 min/max 内。
- 超出容量时，生成器只会在明确支持安全分页时拆页；否则应换页面或人工拆分。
- 设计列表时，每一项的对应文本框、图标和连接关系应具有相同的相对结构。

## 图片组件

```text
@图片组件-内容图-1
@图片组件-装饰图-2
@图片组件-品牌图-3
```

图片索引从 1 开始，按页面阅读顺序对应可见图片目标；页面只有一个图片目标时可以省略索引。

| 类型 | 最终生成时的处理 |
|---|---|
| `内容图` | 必须替换为用户提供或专门生成的图片；只有用户明确批准时才可保留原图。 |
| `装饰图` | 可保留，用于背景、视觉框架和非语义装饰。 |
| `品牌图` | 可保留，用于 logo 或品牌识别。 |

未标注角色的图片会保守地按 `内容图` 处理。

## 序号组件

```text
@序号组件-1
```

用于章节页、步骤页或其他需要显示页内序号的版式。它应对应一个可见的序号形状。

## 标记模板的推荐步骤

1. 先完成 PPT 的视觉版式，包括文字框、列表节点、图片框、品牌元素与装饰。
2. 打开每页的演讲者备注，写入页面类型、属性和逻辑关系。
3. 用页面上真实可见的占位文字作为组件字段名，例如画布上的“本页标题”对应 `@文本组件-本页标题[4-12]`。
4. 对重复节点使用列表组件；不要把多个节点分别写成互不关联的页面级文本字段。
5. 标记每个图片的角色，尤其区分内容图与装饰图。
6. 分析并 lint 模板：

```bash
npm run analyze -- --template "你的模板.pptx" --out "模板输出目录"
npm run lint-template -- --template "你的模板.pptx" --out "模板输出目录"
```

7. 如模板有任何视觉或备注改动，重新分析。生成时会校验模板指纹，旧 manifest 不能继续用于新模板。

## 常见错误

- 一页没有页面类型，或声明了多个页面类型。
- 字段名与页面中可见占位文字不一致，导致解析不到锚点。
- 页面级字段名重复，生成时无法判断应替换哪个文本框。
- 列表项字段没有使用 `@@`，或没有紧随 `@列表组件-Item`。
- 用列表的期望内容量代替视觉容量，造成生成后拥挤或无法分页。
- 把真实内容照片标成装饰图，导致旧模板图片被错误保留。
- 把 SmartArt、复杂自由曲线或难以稳定复制的对象当作动态列表容器；这类页面应改成更安全的模板结构。

## 交付前自查

- 每个字段和列表项都有对应的可见目标。
- 每个字段的 min/max 与该文本框实际可容纳的内容一致。
- 页面类型覆盖封面、目录、章节过渡、内容和结尾。
- 内容图、装饰图、品牌图已正确区分。
- `lint-template` 无 error；若有 warning，确认它不会影响可复用性。
